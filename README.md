# kwootax_landingpage

세무회계 경우 · 미용실 창업 상담 랜딩페이지 (다크 네이비 + 골드)
인스타그램 광고를 통해 유입되는 예비 미용실 원장님을 타겟으로 합니다.

## 구조
- `index.html` - 메인 페이지 (정적)
- `api/lead.js` - 상담 신청 폼 제출 시 이메일 발송 (Vercel Serverless Function)
- `support.js`, `image-slot.js` - 런타임 스크립트
- `assets/hero-calculator.png` - 히어로 이미지

## 상담 폼 → 이메일 발송 설정 (배포 전 필수)

`api/lead.js`는 Gmail SMTP로 메일을 보냅니다. Vercel 프로젝트의
**Settings → Environment Variables**에 아래 값을 등록해야 폼이 정상 동작합니다.

| 변수명 | 값 | 설명 |
|---|---|---|
| `GMAIL_USER` | `kwoo.tax@gmail.com` | 발신 계정 |
| `GMAIL_APP_PASSWORD` | (앱 비밀번호 16자리) | 아래 방법으로 발급 |
| `LEAD_TO_EMAIL` | `kwoo.tax@gmail.com` | 수신 이메일 (생략 시 GMAIL_USER로 발송) |

### 앱 비밀번호 발급 방법
1. `kwoo.tax@gmail.com` 계정에 2단계 인증(2-Step Verification)이 켜져 있어야 합니다.
2. https://myaccount.google.com/apppasswords 접속 → 로그인
3. 앱 이름을 입력하고(예: "경우 랜딩페이지") 생성 → 16자리 비밀번호 발급
4. 이 비밀번호를 Vercel 환경변수 `GMAIL_APP_PASSWORD`에 등록 (공백 없이)

환경변수 등록 후에는 Vercel에서 재배포(Redeploy)해야 반영됩니다.

## 유입 경로 추적 (광고인지 블로그인지, 어떤 키워드인지)

상담 신청 메일 제목 뒤에 유입 경로 요약이 붙고, 본문 아래에 원본 파라미터가 남습니다.
예: `[상담신청] 홍길동 / 010-... · 네이버 검색광고 · 키워드: 미용실세무 · 검색어: 미용실 세무사 · 순위: 2`

구분 기준은 순서대로 이렇습니다.

1. `n_*` 파라미터 → 네이버 검색광고 (키워드·실제 검색어·노출순위까지 확인 가능)
2. `utm_*` → 광고 URL에 직접 붙인 태깅
3. `fbclid` / `gclid` → 메타(인스타·페북) / 구글 광고
4. 파라미터가 없으면 referrer 도메인으로 대분류 (네이버 블로그 / 플레이스 / 자연검색 / 인스타 등)
5. 아무것도 없으면 '직접 유입'

### 네이버 검색광고 키워드를 보려면 (필수 설정)

네이버는 UTM을 자동으로 붙여주지 않습니다. **네이버 검색광고 관리시스템의
자동 추적(Auto Tracking) 기능을 켜야** 광고 클릭 시 랜딩 URL에 `n_query`(실제 검색어),
`n_keyword`(구매 키워드), `n_rank`(노출 순위), `n_ad_group`, `n_ad` 등이 붙습니다.
관리시스템의 '도구' 메뉴에서 설정하며, 메뉴 명칭은 개편될 수 있으니 '자동 추적' 또는
'로그 분석' 항목을 찾아 켜주세요.

이 기능을 켜기 전까지는 광고 유입이 `네이버 광고 클릭 (자동 추적 미설정)` 또는
`네이버 검색 (자연 유입 또는 자동 추적 미설정)`으로만 표기됩니다.

자동 추적을 못 켜는 경우, 광고그룹별 랜딩 URL에 직접 붙여도 같은 효과가 납니다.
`https://도메인/?utm_source=naver&utm_medium=cpc&utm_campaign=<그룹명>&utm_term=<키워드>`

### 최초 유입 기록

광고로 처음 들어왔다가 며칠 뒤 직접 방문해 문의하는 경우가 많아,
브라우저 `localStorage`에 최초 유입 경로를 남겨 메일에 `최초 유입:` 줄로 함께 보냅니다.
광고 성과가 '직접 유입'으로 사라지지 않게 하기 위한 장치입니다.

## 네이버 광고 전환 추적 (프리미엄 로그분석)

키워드별 클릭 대비 전환율을 네이버 관리시스템에서 보기 위한 연동입니다.
신청사이트 `https://kwootax-landingpage-86cn.vercel.app`, 공통 인증키 `s_2ae8c5cfac23`.

### 설치 구조

`index.html` 상단(메타 픽셀 아래)에 두 덩어리가 들어 있습니다.

1. **공통 스크립트** — 네이버가 발급한 원문 그대로입니다.
   검수 대상이므로 **임의로 고치거나 동적 로딩으로 바꾸지 마세요.**
   소스에 `wcslog.js`와 인증키 문자열이 그대로 보여야 검수를 통과합니다.
2. **전환 스크립트** — 이 페이지는 전환 완료 페이지로 이동하지 않고 폼으로 접수되므로,
   상담 신청이 **성공한 시점**에 `kwNaverConv()`를 호출해 전환을 보냅니다.
   메타 픽셀 `Lead`와 같은 지점이며, 한 방문에 한 번만 전송됩니다.

### 전환 유형 확인 필요

`window.KW_NAVER_CONV_TYPE`은 현재 `'2'`(신청/예약)로 두었습니다.
관리시스템의 '설치 및 검수 가이드'에서 발급되는 **전환 스크립트의
`wcs.cnv("타입","값")` 첫 번째 인자**와 반드시 대조해 맞춰야 합니다.
값이 다르면 전환이 다른 유형으로 집계됩니다.

### 검수 요청

자가설치는 설치 후 **검수 요청**을 해야 집계가 시작됩니다.
배포(main 머지 → Vercel 반영)가 끝난 뒤, 안내메일의 '자가설치 후 검수요청'을 진행하세요.
검수는 실제 배포된 사이트를 보므로 **배포 전에 요청하면 실패합니다.**

## 네이버 프리미엄 로그분석 (키워드별 클릭 → 전환 보기)

상담 메일로는 '문의한 사람'만 보입니다. **몇 명이 보고 몇 명이 문의했는지(전환율)** 를
키워드 단위로 보려면 네이버 검색광고의 무료 로그분석을 연동해야 합니다.

스크립트는 `index.html` 상단(메타 픽셀 바로 아래)에 이미 심어져 있고,
**계정 ID만 넣으면 켜집니다.** ID가 비어 있으면 스크립트를 내려받지도 않으므로
지금 상태로 배포해도 아무 문제가 없습니다.

### 설정 순서

1. 네이버 검색광고 관리시스템에 로그인 → '도구' 메뉴에서 **프리미엄 로그 분석** 사용 신청
   (메뉴 명칭은 개편될 수 있으니 '로그 분석' 항목을 찾으면 됩니다)
2. 신청이 승인되면 **공통 스크립트**와 **전환 스크립트**가 발급됩니다
3. 발급된 스크립트 안의 `wcs_add["wa"] = "..."` 값이 계정 ID입니다.
   이 값을 `index.html`의 `window.KW_NAVER_WA`에 넣습니다

```js
window.KW_NAVER_WA = 's_1a2b3c4d5e6f';  // ← 발급받은 계정 ID
```

4. 발급된 **전환 스크립트**의 `wcs.cnv("타입","값")` 첫 번째 인자를 확인해
   `window.KW_NAVER_CONV_TYPE`에 같은 값을 넣습니다. 상담 신청은 보통 '신청/예약'
   유형이며 기본값 `'2'`로 두었습니다. **발급 화면에 적힌 코드와 반드시 대조하세요**
   (유형 코드 체계는 네이버가 변경할 수 있습니다)
5. 발급 스크립트의 `wcs.inflow()`에 도메인이 적혀 있으면
   `window.KW_NAVER_INFLOW_DOMAIN = 'kwootax.co.kr'` 처럼 한 줄 추가합니다.
   없으면 건드리지 않아도 됩니다

### 동작 방식

- 페이지 진입 시 방문 기록을 보냅니다
- 상담 폼 전송이 **성공한 시점**에만 전환을 보냅니다 (메타 픽셀 `Lead`와 같은 지점)
- 전환은 한 방문에 한 번만 전송됩니다 (상단 폼·하단 폼 중복 방지)
- 스크립트 로드보다 폼 전송이 빠른 경우에도 전환을 담아뒀다가 보냅니다

연동 후 집계까지는 하루 정도 걸릴 수 있습니다. 관리시스템의 키워드별 보고서에서
클릭수와 전환수를 함께 보시면 어떤 키워드가 실제 문의로 이어지는지 확인됩니다.

## 배포
정적 파일 + 서버리스 함수 구조라 별도 빌드 과정 없이 Vercel에 그대로 배포됩니다.
`package.json`의 `nodemailer` 의존성은 Vercel이 배포 시 자동으로 설치합니다.
